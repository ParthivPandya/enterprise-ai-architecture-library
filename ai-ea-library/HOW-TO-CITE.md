# How to Cite the Library

> **Document type:** Citation Guide  
> **Audience:** Readers, researchers, and practitioners  

Use the document title, AIEA Reference Library as the corporate author, version or verification date, repository path, and access date.

## Whole Library

```text
AIEA Reference Library. AI Enterprise Architecture Library.
Version 1.1, 2026. Accessed YYYY-MM-DD.
```

## Individual Document

```text
AIEA Reference Library. “<Document Title>.”
Document number or section, version/year.
Repository path: <relative path>. Accessed YYYY-MM-DD.
```

## AIEA Reference Framework Part

```text
AIEA Reference Library. “AIEA-<number>: <Part Title>.”
AIEA Reference Framework, Version 1.0, 2026.
Accessed YYYY-MM-DD.
```

## Citation Notes

- Cite the primary external source as well as this library when relying on a law, standard, benchmark, or named-company outcome.
- Do not cite an illustrative worked example as evidence of a real deployment.
- Include the exact document version or **Last verified** date because volatile technology and regulatory material can change.
