# WG4 — AI Maturity Assessment

WG4 is an organisational label for the AI maturity assessment reference set. It does not indicate a team or delivery state.

## Start here

Complete the [Self-Assessment Instrument](Self-Assessment-Instrument.md), calculate the [Scorecard and Heatmap](Scorecard-and-Heatmap.md), then use [Score-to-Roadmap](Score-to-Roadmap.md) to choose dependency-led capability actions. The facilitation playbook supports a cross-functional assessment.

## Documents

| Document | Description |
|---|---|
| [Self-Assessment Instrument](Self-Assessment-Instrument.md) | Eight dimensions, statements, scoring and evidence rules |
| [Scorecard and Heatmap](Scorecard-and-Heatmap.md) | Deterministic calculation and accessible presentation |
| [Facilitation Playbook](Facilitation-Playbook.md) | Neutral, evidence-based assessment workflow |
| [Score-to-Roadmap](Score-to-Roadmap.md) | Root-cause analysis and dependency-ordered action packages |
