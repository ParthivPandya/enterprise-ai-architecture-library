# Section 09 — Reader Reference Library

Section 09 contains practical, public-facing references for AI governance, AI-native enterprise architecture, AI-assisted architecture practice, maturity assessment and agentic AI.

The labels **WG1** to **WG5** are organisational groupings used only to keep related documents together. They do not indicate teams, ownership, sequence or delivery tracking.

## How to use this section

1. Choose a topic from the catalogue.
2. Start with the workspace README for a suggested reading path.
3. Apply statements labelled **Normative** as the recommended requirements for adopting that document.
4. Treat **Informative** content as explanation or illustration.
5. Tailor guidance to the organisation and obtain qualified advice for legal, regulatory, safety or sector-specific interpretation.
