# WG2 — EA Guides for the AI-Native Enterprise

WG2 is an organisational label for the AI-native enterprise architecture reference set. It does not indicate a team or delivery state.

## Start here

Read [AI-Native Enterprise Architecture](AI-Native-EA-White-Paper.md) for the thesis, then use the principles and reference architecture for design decisions. Use the value and maturity references for evidence and capability choices.
