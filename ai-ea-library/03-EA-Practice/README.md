# 03 — EA Practice

> *The practitioner's workbench. Runbooks, workshops, reference architectures, and operational patterns for the working enterprise architect.*

This section is where strategy meets execution. It provides the tools, patterns, and operational guidance that enterprise architects use daily — from driving AI adoption and making design decisions to running workshops, managing LLMOps, and establishing AI Centers of Excellence.
