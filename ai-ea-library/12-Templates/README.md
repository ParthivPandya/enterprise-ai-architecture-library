# Section 12 — Templates

> Fillable template files and concise fictional examples. Elsewhere the library *describes* these artefacts; here they exist as files you copy, rename and complete.

Every template uses `<angle-bracket placeholders>` for fields you replace and `[ ]` checkboxes for gates. Copy a template into your own repository or document store, do **not** edit the master in place.

The [completed examples](Examples/README.md) use one fictional scenario to demonstrate level of detail and cross-record consistency. Example dates, costs, findings, scores and thresholds are illustrative inputs, not facts, results, endorsements or compliance assurances.

## Example Use

Examples demonstrate completion, including unresolved findings and a no-go decision. They should never be copied as evidence. Replace all illustrative content, assign named accountable individuals in the appropriate controlled system and retain source evidence for each assertion.
