# Release History

This file records published library editions. It is not a progress tracker or future-work plan.

## [1.1.0] — 2026-10-03

### Added
- **Section 09 — Operational Guide Outputs** (`ai-ea-library/09-WG-Outputs/`): twenty completed reader-facing guides across governance, AI-native EA, AI-enhanced EA practice, maturity assessment, and agentic scaling.
- **Section 10 — Use Cases and Worked Examples** (`ai-ea-library/10-Use-Cases-and-Case-Studies/`): five detailed standalone use cases (UC-01–UC-05), two illustrative worked examples, and verified-case-study submission guidance.
- **Section 11 — Architecture Diagrams** (`ai-ea-library/11-Architecture-Diagrams/`): two ArchiMate model-exchange files and two rendered SVG views.
- **Section 12 — Templates** (`ai-ea-library/12-Templates/`): ten fillable templates plus one completed example for each template.
- **AIEA-CW01 Alignment and Evidence Workbook** (`ai-ea-library/05-Standards/`): evidence checklists for NIST AI RMF, EU AI Act, ISO/IEC 42001, and the India DPDP framework.
- **Series Guides** AIEA-G09 (Manufacturing & Industrial AI), AIEA-G10 (Government & Public Sector AI), AIEA-G11 (AI for SMEs), and AIEA-G12 (Defence & Education AI).
- **Repository infrastructure:** `CHANGELOG.md`, GitHub issue templates, `mkdocs.yml`, and a GitHub Actions documentation-deploy workflow.
- **Reader guidance:** role-based journeys, document taxonomy, editorial/citation policy, primary-source register, and legal notice.
- **Modern architecture guidance:** agent interoperability and identity, AI supply-chain governance, context engineering, and resilience.

### Changed
- **AIEA-101 (Part 1):** added the Intended Audience section and the seven-Part documentation-set overview; corrected the Part count from six to seven (including Part 7); fixed the AI-ADM Cycle 3 phase range (G–J); section renumbering (TOGAF Integration is now §1.6).
- **Framework positioning:** clarified that AIEA is independent practitioner guidance and that mappings support alignment rather than establishing compliance or certification.
- **Regulatory accuracy:** corrected blanket data-localisation claims and added role/applicability/effective-date cautions.
- **Sector depth:** expanded G09–G12 with architecture views, controls, failure modes, evaluation guidance, and primary references.
- **Usability:** added explicit site navigation, completed examples, accessible SVG metadata, embedded reference figures, and consistent single-H1 heading structure.
- **Evidence transparency:** converted incomplete source footers to clearly labelled source leads and added a publication-grade citation policy.

- Initial public library: Core Architecture Library (Sections 00–04), the AIEA Reference Framework (Parts 1–7, Section 05), Series Guides G01–G08 (Section 06), Practitioner Toolkits (Section 07), and Domain Portfolios (Section 08).
